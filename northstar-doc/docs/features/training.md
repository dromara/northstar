# 操盘手训练

操盘手训练不是平台里的一个独立菜单，而是一种由 **历史回放 + 模拟盘手工交易** 组合而成的**复盘训练**玩法：把历史行情像录像一样重新播放，你在"身临其境"的行情中用手工下单的方式做交易，练盘感、练纪律、验证交易思路 —— 全程零风险，且可以用远比真实时间快的速度完成。

## 为什么用回放做训练

| 传统复盘 | Northstar 回放训练 |
|---|---|
| 看着静态K线图"脑补"当时会怎么操作 | 行情逐TICK真实重演，**不知道后面走势**，如同身临其境 |
| 只能想想，无法验证 | 真实下单、真实撮合，盈亏立现 |
| 一天行情要花一天复盘 | 可调速，一天的行情几分钟过完 |
| 无法统计训练成果 | 账户绩效自动统计胜率、盈亏曲线 |

## 训练环境搭建（一次性，约 3 分钟）

### 第 1 步：创建回放行情网关

**网关管理 → 新建**：

- 网关用途：**行情**
- 网关渠道：**PLAYBACK**
- 订阅合约：选择你想训练的品种
- **网关配置**：用"近一周/近三月/近一年/近两年"快捷按钮设定训练区间；回放精度建议先选**低**（加载快）

详见 [历史回放](/features/playback#第一步-创建回放网关)。

### 第 2 步：创建训练用模拟账户

再次 **新建**：

- 网关用途：**交易**
- 网关渠道：**SIM**
- 行情网关：**绑定 PLAYBACK 回放网关**（关键！让模拟账户撮合回放行情）

创建后将该网关**连线**，并通过卡片菜单 **出入金** 注入训练资金（例如 10 万）。

### 第 3 步：打开训练界面

进入 **交易中心 → 多图同列**（`Alt+9`）：

- 行情网关：**PLAYBACK**
- 图表数：建议 2~4 图
- 周期：建议一个主周期（如 5m）+ 一个方向周期（如 30m）
- 品种：选择训练品种 → 点**刷新**

展开底部**交易面板**，交易账户选择刚才的 SIM 训练账户。

训练环境就绪后的实际界面如下（上半部分为多图同列回放行情，下半部分为展开的交易面板）：

## 开始训练

### 基本训练循环

```
Alt+Q（预加载）→ Alt+Q（开始回放）→ 观察行情 → 交易面板下单
→ Alt+W（逐K推进，一根K线一根K线地走）→ 持仓管理 → 平仓
→ 重复 → Alt+Q 暂停 → 查看账户绩效复盘
```

### 训练技巧

1. **逐K回放是最核心的训练模式**
   按 `Alt+W` 一根K线一根K线地推进，每根K线出现后问自己："现在该怎么办？" —— 开仓？持有？止损？做出决策并执行，再看下一根K线验证。这完美模拟了实盘决策过程。
   - 用"逐K步长"下拉匹配你的交易周期（5m 交易者选 5m 步长）。

2. **用时间线跳转专攻经典行情**
   回放暂停后（预加载完成状态），直接修改"当前时间线"跳到某个历史时点 —— 例如反复练习某次暴涨暴跌行情的开仓时机。

3. **用画线交易练交易计划**
   K线图上右键 → 画线交易 → 交易计划：画出入场线、止损线、止盈线，系统会显示盈亏比并要求确认。训练"先有计划、后有交易"的纪律，计划触线自动执行，杜绝临时起意。

4. **用调速练反应**
   把回放速度调快，模拟行情快速波动时的决策压力；遇到关键位置再调慢或暂停思考。

5. **练完必复盘**
   交易面板点"账户绩效"图标：
   - **交易记录**：逐笔回看每笔交易的开平仓位置（配合"显示历史持仓线"，直接在K线图上看买卖点）；
   - **交易统计**：盈亏分布、交易笔数、盈亏合计；
   - **盈亏曲线**：资金曲线是训练成果最直观的体现。

![账户绩效复盘](/images/sim-account-performance.png)

### 重置再练

`Alt+S` 状态重置后回放回到起点，可以换一段区间（修改回放网关的日期配置），或者重新挑战同一段行情 —— 同一个品种同一段行情，多练几遍，对比几次的绩效曲线，检验自己是否真的"学会了"。

## 推荐训练计划

| 阶段 | 目标 | 做法 |
|---|---|---|
| 入门 | 熟悉操作 | 近一周数据 + 低精度 + 逐K回放，熟悉下单、平仓、撤单 |
| 进阶 | 建立交易系统 | 固定一套进出场规则，在近三月数据上严格执行，统计胜率与盈亏比 |
| 强化 | 压力训练 | 调快回放速度，或选择剧烈波动的行情段，训练纪律执行力 |
| 检验 | 盲测 | 换一段从未看过的区间（近一年/近两年），不看结果完整做完，最后看绩效 |

## 从手工训练到程序化

当你在训练中沉淀出稳定的交易规则后，可以把它写成交易策略（Java 类），创建用途为"回测"的模组在同样的历史区间上自动运行 —— 对比"手工训练的绩效"与"程序化执行的绩效"，检验规则的客观性与自己的情绪损耗。详见 [程序化交易](/features/auto-trading)。
