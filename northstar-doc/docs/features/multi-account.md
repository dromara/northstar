# 多账户交易

Northstar 的多账户模型非常简洁：**网关即账户**。每创建一个用途为"交易"的网关，就接入了一个实际交易账户；创建任意多个交易网关，即可在一个平台内统一管理多个账户（不同期货公司、不同市场、模拟与实盘混管均可）。

## 一、接入多个账户

在 **网关管理** 中为每个账户创建交易网关：

| 字段 | 说明 |
|---|---|
| 网关渠道 | CTP（期货实盘）/ TIGER / OKX / BIAN / SIM（模拟）等 |
| 网关用途 | **交易** |
| 行情网关 | 为该账户绑定一个行情网关（行情与交易分离，可多个账户共享一个行情网关） |
| 连线方式 | 建议开启**自动连线**，平台启动后自动连接 |
| 网关配置 | 各渠道的账户凭据等配置，在"网关配置"弹窗中按动态表单填写 |

每个网关卡片独立显示连接状态（已连接/已断开，行情网关另有"行情：活跃/不活跃"标签），可分别 **连线 / 断开**，互不影响。

::: tip 典型组合
- 期货公司 A 账户 + 期货公司 B 账户：两个 CTP 交易网关共享一个 CTP 行情网关；
- 模拟账户与实盘账户并存：SIM 网关练手，CTP 网关跑实盘，互不影响。
:::

## 二、交易面板多账户切换

底部交易面板的 **交易账户** 下拉列出全部交易网关。切换账户后：

- 账户权益 / 可用金额 / 资金使用率；
- 持仓、挂单、计划、委托、成交五个标签页；

全部切换为该账户的数据，下单请求也发往该账户。多账户手工交易只需一次切换。

## 三、一个模组驱动多个账户

新建/修改模组时，**绑定账户** 是多选框 —— 选一个策略同时绑定多个交易账户，模组会按"合约 → 账户"的映射把信号分发到各个账户下单。

这是多账户程序化交易的核心用法：

- **一套策略，多账户复制**：同一信号在多个账户同步执行，无需为每个账户单独建模组；
- **模组账户独立记账**：模组内部有自己的逻辑账本（模组账户），按"分配金额"控制风险，与各实际账户资金解耦。

::: info 分配金额的作用
模组的"分配金额"是模组账户的额度，决定策略能动用多少资金，与账户实际余额无关。多账户场景下，可用"分配金额 + 默认下单量"统一控制每个账户的交易规模。
:::

## 四、合约配置

**合约配置** 菜单按合约维度设置交易参数，支持批量操作与导入导出：

- **杠杆 / 保证金**：影响资金占用计算；
- **手续费**：影响绩效统计的准确性；
- **交易时段**：影响交易时间判断。

::: warning
仅 **PLAYBACK**（回放）网关的合约支持自定义保证金与手续费（用于回测假设）；实盘渠道的合约参数由网关接入时确定。
:::

## 五、多账户行情总览

**交易中心 → 活跃行情报价**（`Alt+8`）以表格汇总所有行情网关的实时报价：

- 列：名称、最新价、涨跌、涨幅%、成交量、持仓量、日增仓、报价时间；
- 可按 **行情网关** 筛选（全部 / 指定渠道），按合约名或代码搜索；
- 支持分页（10 ~ 100 条/页）。

多账户各自绑定了不同行情网关时，可在此统一盯盘。

## 六、多账户使用建议

| 场景 | 推荐做法 |
|---|---|
| 手工同时盯多个账户 | 交易面板切换账户 + 活跃行情报价统一盯盘 |
| 同一策略跑多个账户 | 一个模组绑定多个账户 |
| 不同策略跑不同账户 | 每"策略 × 账户组合"建一个模组，用模组名称区分 |
| 实盘前验证 | 先用 SIM 账户跑"模拟盘"模组，再切换到实盘账户建"实盘"模组 |
| 风险控制 | 为每个模组设定独立的分配金额，模组间资金互相隔离 |
