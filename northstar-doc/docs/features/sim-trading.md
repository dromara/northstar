# 模拟盘交易

模拟盘通过内置的 **SIM 渠道** 提供一个零风险的仿真交易环境：行情与撮合都在本地模拟完成，账户数据持久化保存，关掉重开数据不丢失。它适用于：

- 新用户熟悉平台交易操作；
- 手工交易练习（配合历史回放即 [操盘手训练](/features/training)）；
- 策略上实盘前的模拟验证（模组用途选"模拟盘"）。

## 创建模拟网关

SIM 渠道同时支持行情与交易两种用途，且**无需任何网关配置**。建议创建一对网关：

### 1. 模拟行情网关

**网关管理 → 新建**：

| 字段 | 填写 |
|---|---|
| 网关用途 | **行情** |
| 网关渠道 | **SIM** |
| 订阅合约 | 选择需要的模拟合约（平台内置 3 个模拟合约） |

### 2. 模拟交易网关（模拟账户）

再次 **新建**：

| 字段 | 填写 |
|---|---|
| 网关用途 | **交易** |
| 网关渠道 | **SIM** |
| 行情网关 | 绑定上面创建的 SIM 行情网关 |

创建后点网关卡片的 **连线**，卡片出现绿色的"已连接"标签即表示就绪。

::: tip 一个 SIM 交易网关 = 一个模拟账户
想练多种策略或多人对比？多建几个 SIM 交易网关即可拥有多个互相独立的模拟账户，详见 [多账户交易](/features/multi-account)。
:::

## 出入金

新账户需要注入虚拟资金才能交易：

1. 在 SIM 交易网关卡片右上角"更多"下拉中选择 **出入金**；
2. 弹窗显示"【账户名】账户余额"；
3. 输入 **出入金额**（步进 100,000；**正数入金、负数出金**），点击 **OK**。

![模拟账户出入金](/images/sim-deposit.png)

## 手工下单

桌面端所有页面底部都有**交易面板**，点击中间横条展开。左侧为下单区：

![底部交易面板](/images/sim-trade-panel.png)

| 字段 | 说明 |
|---|---|
| **交易账户** | 下拉选择用哪个账户下单（列出全部交易网关，支持多账户切换） |
| 账户信息 | 只读显示：账户权益 / 可用金额 / 资金使用率 |
| **交易合约** | 只列出该账户已订阅的合约 |
| **交易量** | 下单手数 |
| **价格类型** | 市价 / 对手价 / 排队价 / 限价（限价时可编辑价格） |
| **价格** | 仅限价单可输入 |

三个下单按钮（按钮上直接显示按当前行情计算的委托价）：

- 🔴 **买开**：开多仓
- 🟢 **卖开**：开空仓
- ⚪ **平仓**：平掉选中的持仓（先开先平 FIFO，需先在持仓列表中选中一行）

交易面板左侧还有三个图标按钮：

- **浮窗模式**：下单表单弹出为独立浮窗，方便拖动；
- **显示/隐藏历史持仓线**：在K线图上标注历史持仓区间（仅 SIM 账户）；
- **账户绩效**：打开绩效分析弹窗（仅 SIM 账户）。

## 账户数据标签页

交易面板右侧以标签页展示当前账户的实时数据：

| 标签页 | 内容 |
|---|---|
| **持仓** | 合约名称、方向、总持仓、可用持仓、开仓均价、持仓盈亏 |
| **挂单** | 未成交委托，带**撤单**按钮 |
| **计划** | 画线交易计划列表（入场/止损/止盈/盈亏比） |
| **委托** | 当日全部委托记录 |
| **成交** | 当日全部成交记录 |

## 画线交易

在"多图同列"的K线图上**右键 → 画线交易**，可以直接在图上画出：

- **多头 / 空头**：画出入场位置即生成开仓计划；
- **止盈 / 止损**：为持仓设定离场线；
- **交易计划**：组合入场、止损、止盈，弹窗会显示盈亏比并要求确认。

画线计划生成后显示在交易面板的"计划"标签页中，行情触线自动执行。

::: warning 前提
画线交易需要先在交易面板选定**交易账户**，否则无法提交。
:::

## 账户绩效复盘

在交易面板点击"账户绩效"图标，打开绩效弹窗，包含三个标签页：

![账户绩效](/images/sim-account-performance.png)

- **交易记录**：逐笔开平仓明细；
- **交易统计**：盈亏分布、交易笔数、盈亏合计，支持按"净盈亏曲线 / 合约统计"切换统计口径；
- **盈亏曲线**：账户权益变化曲线。

这是手工交易与操盘手训练后复盘总结的核心工具。

## 程序化模拟交易

让策略在模拟盘自动运行：新建模组时**模组用途选"模拟盘"**，绑定 SIM 交易账户即可。详见 [程序化交易](/features/auto-trading)。
