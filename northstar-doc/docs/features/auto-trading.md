# 程序化交易

程序化交易以 **模组（Module）** 为核心运行单元：**模组 = 策略 × 账户 × 合约**，即"哪个策略在哪个账户上对哪个品种进行交易"。创建模组并启用后，策略便会自动接收行情、发出交易信号并下单。

## 模组管理页

进入 **交易自动化 → 模组管理**（`Alt+2`），表格展示全部模组：

![模组管理页](/images/auto-module-mgmt.png)

| 列 | 说明 |
|---|---|
| 模组名称 | 唯一标识 |
| 模组类型 | 投机 / 套利 |
| 模组用途 | 回测 / 模拟盘 / 实盘 |
| 交易策略 | 绑定的策略 |
| 平仓逻辑 | FIFO 先开先平 / FILO 平今优先 / CPHT 平昨锁今（悬停显示全称） |
| 交易账户 / 交易合约 | 绑定的账户与合约 |
| 模组状态 | 无持仓 / 多头持仓 / 空头持仓 / 对冲锁仓 / 对冲持仓 / 等待中 / 异常 |
| 启停状态 | 已启用 / 已停用 |

勾选多行后，"启用/停用"变为**批量操作**。每行的"操作"下拉提供：

- **启用 / 停用**：启停模组（快捷键之外最常用的操作）；
- **修改**：仅停用状态可修改；
- **复制**：以该模组为模板快速创建新模组；
- **运行时状态**：打开模组监控详情页（见下文）；
- **查看日志**：跳转该模组的专属日志；
- **重置**：清空模组账户与持仓（需确认）；
- **移除**：仅停用状态可删除。

## 新建模组

点击 **新建**，弹窗分为四个页签：

![新建模组弹窗](/images/auto-module-create.png)

### ① 模组信息

| 字段 | 说明 |
|---|---|
| 模组名称 | 不超过 16 个字符，创建后不可改 |
| 分配金额 | 模组账户的初始资金（默认 10000） |
| 模组类型 | 投机 / 套利 |
| 模组用途 | **回测** / **模拟盘** / **实盘** |
| 平仓逻辑 | 先开先平 / 平今优先 / 平昨锁今（平昨锁今仅实盘可选） |
| 预热数据量 | 加载多少周的历史数据用于指标预热（回测用途强制为 0，由回放网关控制预热） |
| 图表数据量 | 模组缓存的K线条数（默认 500，最小 100） |
| 默认下单量 | 每次开仓的手数单位（既可作每次开仓量也可作最大开仓量，由策略实现决定） |
| 超价 | 在限价基础上优惠 N 个价位，提高成交率（单位：价位） |

### ② 交易策略

- 勾选 **显示示例策略** 可显示/隐藏平台自带的示例策略；
- **绑定策略** 下拉选择策略（创建后不可改）；
- 选中策略后会**动态渲染该策略的可调参数**：下拉类参数渲染为选择器，其余渲染为输入框（带单位）。

### ③ 账户与合约

- **绑定账户**：多选，列出全部交易网关 —— 一个模组可同时驱动多个账户（详见 [多账户交易](/features/multi-account)）；
- **绑定合约**：远程搜索多选，可选项来自所选账户已订阅的合约。

### ④ 已关联合约

只读表格，展示合约名称与用于交易算法的合约编码（可选中复制）。

底部按钮：**取消 / 保存 / 保存并继续**（新建时保存后清空名称，方便连续创建多个模组）。

## 模组运行时

在模组管理页点 **运行时状态**，进入模组监控详情页：

![模组运行时状态](/images/auto-module-runtime.png)

- **K线图表区**：可切换周期（1m ~ 1wk），主图 + 最多 5 个副图窗格；支持增加/移除/清空指标、显示（隐藏）历史持仓线、下载图表数据（CSV）、自动刷新开关；
- **实时状态 / 历史表现** 两个标签页；
- **模组信息**：当前余额、可用金额、占用金额、初始金额、总盈亏、总平仓盈亏、未平仓盈亏、总手续费、交易笔数、胜率、盈亏比、年化收益率、最大回撤、最大回撤率；
- **手工调仓**：开多 / 开空 / 平空 / 平多 + 提交 —— 直接干预模组持仓，用于应急处理；
- **模组持仓**、**模组交易历史**、**模组绩效** 图表。

::: tip 回测模组也在这里看
用途为"回测"的模组在 [历史回放](/features/playback) 运行时，同样通过本页实时观察策略在历史行情上的表现；"历史表现"页展示完整回测绩效。
:::

## 策略从哪来

平台中的策略是实现了策略接口的 Java 类，有两种来源：

1. **内置示例策略**：平台自带约 11 个示例策略（名称含"示例"，模组表单默认隐藏，勾选"显示示例策略"可见），供学习参考；
2. **自研策略 jar 动态加载**：把编译好的策略 jar 放到程序 jar 的**同级目录**，重启平台即被自动扫描注册，出现在"绑定策略"下拉中。

::: info 策略开发
策略开发属于开发话题：继承 `AbstractStrategy`、标注 `@StrategicComponent("策略名")`、可选定义 `InitParams` 内部类暴露可调参数。仓库中的 `northstar-strategy-example` 模块提供了完整示例，也可使用平台内置的 AI 助手（策略编写助手）辅助编写。
:::

## 策略探索（批量回测）

**交易自动化 → 策略探索** 用于批量验证策略：一个任务 = 一个策略 × 一组合约 × 一段历史区间，跑完直接出**回测报告**，适合参数寻优与品种筛选。

![策略探索](/images/auto-strategy-explorer.png)

### 新建任务

点击新建，弹窗三页签：

1. **任务信息**：任务名称（≤16 字符）、预热起始日（默认 18 个月前）、测试开始日（默认 12 个月前）、测试结束日（默认今天）、分配金额（默认 20000；*回测交易量按分配金额的一半计算*）；
2. **交易策略**：选择策略并填写参数（同模组表单）；
3. **测试合约**：多选要测试的合约。

### 运行与报告

- 任务列表每 5 秒自动刷新，显示进度条；
- 行操作：**详情**（查看设置）、**回测**（启动回测，进行中禁用）、**移除**、**回测报告**；
- **回测报告** 表格按合约逐行列出：交易合约、交易量、当前余额、交易笔数、总手续费、未平仓盈亏、总平仓盈亏、年化收益率%（可排序）、盈亏比（可排序）、胜率%（可排序）、最大回撤；
- 每行可打开 **交易详情**：盈亏分布、交易笔数、盈亏合计统计，记录过多时可下载。

## 模组状态速查

| 状态 | 含义 |
|---|---|
| 无持仓 | 空闲，等待信号 |
| 多头持仓 / 空头持仓 | 持有单向仓位 |
| 对冲锁仓 / 对冲持仓 | 双向持仓（锁仓） |
| 等待中 | 已下单，等待订单反馈 |
| 异常 | 运行出错，请查看模组日志排查 |

## 策略上线推荐流程

```
策略探索批量回测 → 创建"回测"模组精细验证 → 创建"模拟盘"模组试运行 → 创建"实盘"模组上线
```
