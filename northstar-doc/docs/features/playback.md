# 历史回放

历史回放是 Northstar 的核心特色功能：它将指定区间的**历史行情**按设定的节奏重新"播放"出来，就像观看行情录像一样。它是以下场景的共同基础：

- **策略回测**：让策略在历史行情中跑一遍，检验策略表现；
- **操盘手训练**：在回放行情中手工下单，进行复盘练习（详见 [操盘手训练](/features/training)）；
- **行情研究**：随时回看任意时间段的市场走势。

## 工作原理

回放在平台中体现为一个特殊的行情网关：

- 渠道为 **PLAYBACK**，网关 ID 固定为 `PLAYBACK`，用途只能是**行情**；
- 回放的历史数据来自平台的数据服务；
- 回放出的行情与实时行情**完全同构**——K 线图、交易面板、程序化模组都感觉不到差别，因此策略代码无需任何修改即可在历史与实盘间切换。

回放状态机：

```
INITIAL（初始） → PRELOADING（预加载中） → PRELOADED（预加载完成） → PLAYING（回放中） → FINISHED（回放结束）
                                            ↕ 可跳转时间线        ↕ 可暂停/逐K
```

## 第一步：创建回放网关

进入 **网关管理**（`Alt+1`），点击右上角 **新建**：

| 字段 | 填写说明 |
|---|---|
| 网关 ID | 行情网关自动等于渠道名（`PLAYBACK`），无需修改 |
| 网关描述 | 自定义备注 |
| 网关用途 | 选择 **行情** |
| 连线方式 | PLAYBACK 渠道不支持自动连线，保持关闭 |
| 网关渠道 | 选择 **PLAYBACK** |
| 订阅合约 | 多选需要回放的合约（即"回放哪些品种"） |

然后点击弹窗底部的 **网关配置**，设置回放区间与精度：

| 配置项 | 说明 |
|---|---|
| **预热起始日** | 回放正式开始前先加载的历史数据起点，用于让指标"预热"（可选） |
| **开始日** | 回放开始日期（YYYYMMDD，不能早于 2021-01-01） |
| **结束日** | 回放结束日期 |
| **回放精度** | 低（每分钟 4 个 TICK）/ 中（每分钟 30 个 TICK）/ 高（每分钟 120 个 TICK） |

弹窗顶部提供 **近一周 / 近三月 / 近一年 / 近两年** 四个快捷按钮，一键填充日期区间。

::: tip 精度如何选择
- 看日线/小时线级别的复盘，选**低**精度即可，加载最快；
- 需要在分钟级观察盘口节奏，选**中**；
-  tick 级精细回测选**高**，但数据量与加载时间会显著增加。
:::

## 第二步：打开回放控制面板

有两种方式打开**历史回放控制面板**（非模态窗口，可拖动）：

1. **网关管理** → 找到 PLAYBACK 网关卡片 → 右上角"更多"下拉 → **回放**；
2. **多图同列**页面 → 数据类型选"回放" → 头部回放控制区点"更多"图标。

控制面板各控件说明：

| 控件 | 说明 |
|---|---|
| **当前时间线** | 显示回放当前时间；仅在"预加载完成"状态下可编辑，改时间即**跳转**到该时间点 |
| **数据预加载** ⏩ | 加载回放区间的数据（仅初始状态可用），快捷键 `Alt+Q` |
| **开始回放** ▶ | 预加载完成后启动回放，快捷键 `Alt+Q` |
| **暂停回放** ⏸ | 暂停，快捷键 `Alt+Q` |
| **逐K回放** ⏭ | 每按一次向前推进一根K线，快捷键 `Alt+W` |
| **状态重置** 🔄 | 回到初始状态（同时重置所有回测模组），快捷键 `Alt+S` |
| **回放速度** | 滑块无级调速，提示"每TICK间隔 n 毫秒"，范围从"正常"到"极速" |
| **逐K步长** | 逐K回放时每次推进的K线周期：1m / 3m / 5m / 10m / 15m / 30m / 1h / 2h / 4h |

## 第三步：观看回放行情

进入 **交易中心 → 多图同列**（`Alt+9`）：

1. 头部 **数据类型** 选择 **回放**；
2. 选择 **图表数**（1/2/3/4/5/6/9/12 宫格）、**周期**（可多选，1m ~ 1d/1wk）、**品种**（可多选）；
3. 点击 **刷新**，图表会加载回放时间线之前的历史K线；
4. 用头部内联的回放按钮（预加载/播放/暂停/逐K/更多）或快捷键控制回放，行情便会在图表上"活"起来。

图表还支持：

- **右键菜单**：切换品种、指标参数设置、全屏、截图；
- **画线工具**：直线、水平线、斐波那契、三浪五浪等技术分析画线；
- **画线交易**：在图上画出多头/空头/止盈/止损/交易计划（需先在交易面板指定交易账户）；
- **图表通用设定**（头部"设置"按钮）：红涨绿跌/绿涨红跌、历史持仓线、主图/副图指标。

## 第四步：查看回放结果

- **程序化回测**：用途为"回测"的模组，在 **模组管理 → 运行时状态** 查看实时绩效（余额、盈亏、胜率、最大回撤等），详见 [程序化交易](/features/auto-trading)；
- **手工交易复盘**：在交易面板点"账户绩效"图标，查看交易记录、交易统计与盈亏曲线；
- **批量回测**：使用 **策略探索** 页面对"一个策略 × 多个合约"批量跑回测并生成回测报告，详见 [策略探索](/features/auto-trading#策略探索-批量回测)。

::: warning 注意
**状态重置**会同时重置所有用途为"回测"的模组（清空其账户与持仓）。如果回测模组正在跑出满意的结果，先记录绩效再重置。
:::

## 常见问题

**Q：预加载很慢？**
回放区间越长、精度越高、订阅合约越多，预加载越慢。建议先用"近一周"+ 低精度熟悉流程。

**Q：回放途中想跳到某个时点？**
暂停后，等状态回到"预加载完成"即可直接修改"当前时间线"进行跳转。

**Q：回放与"策略探索"的回测有什么区别？**
回放是"可视化、可交互"的，行情逐TICK播放，可以中途暂停、手工下单；策略探索是"静默批量"的，跑完直接出报告，适合参数寻优。
