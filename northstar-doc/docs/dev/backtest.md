# 回测与策略探索

> 「扩展 · 程序化交易」系列之一。前置阅读：[策略开发](/dev/strategy)（写出你的第一个策略）、[历史回放](/features/playback)（回放网关的使用）。

写完一个策略，怎么知道它"行不行"？平台提供**由粗到精**的三级验证手段，本文逐一说明用法、报告怎么读、以及新手最容易踩的坑。

## 推荐验证路径

```
① 策略探索（批量回测）  →  ② 回测模组（精细验证）  →  ③ 模拟盘模组（实盘彩排）  →  ④ 实盘模组
     品种筛选、粗调参数         逐笔复盘、看图调指标           实时仿真、检验稳定性
```

- **策略探索**：一次任务跑"一个策略 × 多个合约"，横向对比哪个品种表现好，适合**海选**；
- **回测模组**：针对入选的品种，用模组的完整运行机制（状态机、持仓、日志、图表）逐笔验证，适合**精调**；
- **模拟盘**：SIM 模拟账户 + 实时行情，检验策略在"行情不确定到来"下的稳定性，适合**彩排**。

## 策略探索：批量回测

入口：**交易自动化 → 策略探索**。一个任务 = 一个策略 × 一组合约 × 一段历史区间。

### 新建任务

弹窗分三个页签：

1. **任务信息**：任务名称（≤16 字符）、**预热起始日**（默认 18 个月前）、**测试开始日**（默认 12 个月前）、**测试结束日**（默认今天）、分配金额（默认 20000；回测交易量按分配金额的一半计算）；
2. **交易策略**：选择策略并填写参数（表单由 `@Setting` 自动生成，与建模组一致）；
3. **测试合约**：多选要测的合约。

三个日期把历史切成两段：**[预热起始日, 测试开始日)** 是预热段，只喂数据不产生交易（给指标递推预热，同实盘的"预热数据量"）；**[测试开始日, 测试结束日]** 才是统计绩效的测试段。

### 运行与报告

任务列表每 5 秒自动刷新显示进度；行操作：**回测**（启动）、**详情**、**回测报告**、**移除**。

**回测报告**按合约逐行列出，并可按年化收益率、盈亏比、胜率排序：

| 指标 | 口径 |
|---|---|
| 交易量 | 回测期间的总成交手数 |
| 当前余额 / 分配金额 | 期末资金（分配金额减半作为回测资金） |
| 交易笔数 | 一对开平仓记一笔 |
| 总平仓盈亏 / 未平仓盈亏 | 已实现 / 浮动盈亏 |
| 年化收益率 | 按测试区间折算年化 |
| 盈亏比 | 平均盈利 ÷ 平均亏损（绝对值） |
| 胜率 | 盈利笔数 ÷ 总笔数 |
| 最大回撤 | 区间权益最高点到之后最低点的最大跌幅 |

每行还能打开 **交易详情**：盈亏分布、逐笔成交记录（可下载），以及**与模组运行时同一套**的 K 线图表——策略注册的所有指标按组显示、可叠加观察，逐笔复盘"当时指标长什么样、策略为什么在这里开仓"。

## 回测模组：精细验证

回测用途的模组绑定 [历史回放](/features/playback) 行情网关：先为回放网关预加载数据，再启用模组、启动回放，历史 K 线便一根根流入模组，策略照常走完整的开平仓流程（模组状态机、账户账本、手续费全部生效）。

与策略探索的差别：

- **运行机制 = 实盘机制**：同样的 `onMergedBar` 回调、同样的状态机与下单路径，验证的是"策略本身"而非"批量统计"；
- **过程可观察**：[模组运行时](/features/auto-trading#模组运行时) 页面实时展示 K 线、指标、持仓线；回放暂停时画面定格，可从容分析；
- **预热由回放控制**：回测模组的"预热数据量"强制为 0，预热靠回放数据本身（回放起点早于测试起点即可）；
- **事后可复盘**："历史表现"页给出完整绩效；模组日志记录策略打印的每一行。

::: tip 一次典型的精调循环
回放跑一段 → 在交易详情里发现"这里不该开" → 改策略参数或逻辑 → 重置模组 → 重跑。改代码后需重新打包部署（外部 jar 策略重启生效）。
:::

## 怎么读回测结果：新手的五个坑

1. **只看收益率不看回撤**：年化 100% 伴随 60% 回撤的策略无法实盘。回撤看两点——幅度能否承受、修复需要多久；
2. **样本内过拟合**：参数越多、测试区间越短，越容易"背答案"。同一个参数组合，换一段区间（或换几个相近品种）再跑一遍，结论还成立才算数；
3. **交易笔数太少**：十几笔的胜率、盈亏比没有统计意义（平台的强化学习训练把"≥100 笔"作为达标线，值得参考）；
4. **忽略手续费**：高频策略的回测盈利可能被手续费全部吃掉。回测已计入手续费，重点看"总手续费"一行；
5. **信号不成交≠策略没逻辑**：先确认测试区间确实有行情数据、策略参数（合约编码、周期）填写正确，再看信号条件是否过于苛刻。
