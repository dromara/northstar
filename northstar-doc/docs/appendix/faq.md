# 常见问题（FAQ）

## 登录与安全

**Q：默认账号密码是什么？如何修改？**
默认 `admin` / `123456`。通过环境变量 `NS_USER` / `NS_PWD` 修改，生产部署务必修改。

**Q：登录失败被锁定怎么办？**
账户连续失败 3 次锁定；IP 失败 5 次冻结 1 小时，冻结期间再失败封禁 1 天。等待解锁或重启平台。

**Q：页面提示会话失效？**
平台使用 Session + CSRF Token 机制，长时间未操作需重新登录。

## 网关与账户

**Q：为什么"新建网关"按钮点不了 / 提示禁止操作？**
演示模式（demo profile）下禁止创建、修改、删除网关与回测任务。

**Q：CTP 渠道在下拉里看不到？**
本发行版只内置 PLAYBACK 与 SIM 渠道。CTP 等实盘网关由外部 jar 提供，需将网关 jar 放到程序 jar 同级目录后重启（启动脚本通过 `-Dloader.path` 加载）。CTP_SIM 渠道仅超级用户模式可见。

**Q：网关显示"已断开"？**
点卡片"连线"手动重连；若开启了"自动连线"，平台会按渠道自身的重连机制处理。检查网络与网关配置中的凭据是否正确。

**Q：一个账户想同时跑多个策略可以吗？**
可以。每个策略建一个模组，多个模组可绑定同一个交易账户；每个模组有独立的模组账户（分配金额）控制风险。

## 历史回放

**Q：回放数据从哪来？**
来自平台数据服务（marketplace.quantit.tech），需保证服务器能访问外网且订阅有效（首页"已购服务"可查看订阅与到期日）。

**Q：预加载失败或很慢？**
检查数据服务订阅是否到期；缩短回放区间、降低回放精度、减少订阅合约数量。

**Q：日期为什么选不了 2021 年之前？**
回放数据最早支持 2021-01-01。

**Q：状态重置会丢失什么？**
重置回放会同时重置所有"回测"用途的模组（清空模组账户与持仓），不影响模拟盘/实盘模组。

## 模拟盘与交易

**Q：SIM 账户的钱从哪来？**
通过网关卡片"更多 → 出入金"注入虚拟资金，正数入金、负数出金。

**Q：为什么"账户绩效"按钮是灰的？**
账户绩效与历史持仓线功能仅对 SIM 账户开放。

**Q：画线交易没反应？**
先在交易面板选择交易账户，再在图表右键菜单使用画线交易。

## 程序化交易

**Q：我的策略 jar 放哪？**
放到程序 jar（`northstar-x.y.z.jar`）同级目录，重启平台后即可在模组"绑定策略"下拉中看到。

**Q：为什么策略下拉里看不到示例策略？**
模组表单的"显示示例策略"复选框默认不勾选。

**Q：模组显示"异常"状态？**
进入 **日志中心 → 模组日志** 查看该模组的错误日志定位原因；处理后可在模组管理中重置并重新启用。

**Q：修改模组为什么提示要先停用？**
运行中（已启用）的模组不允许修改，先停用再修改；重新启用即生效。
