# 选项速查表

本文汇总平台中各类下拉选项与术语对照，供查阅。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt + \`` | 首页 |
| `Alt + 1` | 网关管理 |
| `Alt + 2` | 模组管理 |
| `Alt + 8` | 活跃行情报价 |
| `Alt + 9` | 多图同列 |
| `Alt + 0` | 平台日志 |
| `Alt + Q` | 回放：预加载 / 播放 / 暂停（按状态智能切换） |
| `Alt + W` | 回放：逐K回放 |
| `Alt + S` | 回放：状态重置 |

## 网关渠道（ChannelType）

| 渠道 | 行情 | 交易 | 说明 |
|---|:-:|:-:|---|
| PLAYBACK | ✅ | ❌ | 历史回放（内置） |
| SIM | ✅ | ✅ | 模拟撮合（内置，零配置） |
| CTP | ✅ | ✅ | 期货实盘（外部 jar） |
| CTP_SIM | ✅ | ✅ | CTP 仿真（仅超级用户可见） |
| TIGER | ✅ | ✅ | 老虎证券（外部 jar） |
| OKX | ✅ | ✅ | OKX（外部 jar） |
| BIAN | ✅ | ✅ | 币安（外部 jar） |

## 回放选项

| 选项 | 取值 | 说明 |
|---|---|---|
| 回放精度 | 低 / 中 / 高 | 每分钟 4 / 30 / 120 个 TICK |
| 回放速度 | 滑块无级调节 | 提示"每TICK间隔 n 毫秒"，正常 ↔ 极速 |
| 逐K步长 | 1m / 3m / 5m / 10m / 15m / 30m / 1h / 2h / 4h | 逐K回放每次推进的周期 |
| 回放状态 | INITIAL → PRELOADING → PRELOADED → PLAYING → FINISHED | 初始 → 预加载中 → 预加载完成 → 回放中 → 已结束 |

## K线周期

`1m` `3m` `5m` `10m` `15m` `30m` `1h` `2h` `4h` `1d` `1wk`

## 下单价格类型

| 选项 | 说明 |
|---|---|
| 市价 | 以当前市场最优价立即成交 |
| 对手价 | 以对手方报价委托（买入取卖一价，卖出取买一价） |
| 排队价 | 以己方排队价委托（买入取买一价，卖出取卖一价） |
| 限价 | 自定义价格委托 |

## 模组选项

### 模组用途

| 用途 | 说明 |
|---|---|
| 回测 | 在历史回放环境中运行策略 |
| 模拟盘 | 在 SIM 模拟账户上试运行策略 |
| 实盘 | 在实盘账户上真实交易 |

### 模组类型

投机 / 套利

### 平仓逻辑

| 选项 | 全称 | 说明 |
|---|---|---|
| FIFO | 先开先平 | 按开仓顺序平仓 |
| FILO | 平今优先 | 优先平今日新开仓位 |
| CPHT | 平昨锁今 | 平昨仓同时锁住今仓（仅实盘可选，适用于有平今高手续费的品种） |

### 模组状态

| 状态 | 含义 |
|---|---|
| 无持仓 | 空闲 |
| 多头持仓 / 空头持仓 | 单向持仓 |
| 对冲锁仓 / 对冲持仓 | 双向持仓 |
| 等待中 | 已下单等待订单反馈 |
| 异常 | 运行出错（查模组日志） |

### 网关连接状态

连接中 / 已连接 / 断开中 / 已断开；行情网关另有 行情：活跃 / 不活跃。

## 图表工具

- **图表数**：1 / 2 / 3 / 4 / 5 / 6 / 9 / 12 宫格
- **画线工具**：直线、水平线、斐波那契、三浪五浪等
- **画线交易**：多头、空头、止盈、止损、交易计划
- **图表通用设定**：K线配色（红涨绿跌 / 绿涨红跌）、历史持仓线、主图/副图指标

## 环境 Profile（部署参考）

| Profile | 端口 | SSL | 数据库 |
|---|---|---|---|
| `prod`（默认）/ `demo` | 443 | 启用 | H2 文件模式 |
| `dev` | 80 | 禁用 | H2 文件模式 |
| `test` / `unittest` / `train` / `devtest` | 80 | 禁用 | H2 内存模式 |

通过 `-Denv=<profile>` 启动参数切换，如 `java -Denv=dev -jar northstar-x.y.z.jar`。
