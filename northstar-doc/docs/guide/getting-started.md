# 快速上手

::: tip 还没安装平台？
请先阅读 [安装与启动](/guide/installation)，完成环境准备、软件包下载与数据服务配置后再回来。
:::

## 登录平台

在浏览器中打开平台地址（生产环境默认 `https://<服务器IP>`，端口 443；开发环境为 80），进入登录页：

- **账号**：默认为 `admin`
- **密码**：默认为 `123456`
- **记住我**：勾选后浏览器会记住账号密码

::: warning 安全提示
- 默认账号密码可通过环境变量 `NS_USER` / `NS_PWD` 修改，生产部署时务必修改。
- 连续登录失败 3 次账户会被锁定；同一 IP 失败 5 次冻结 1 小时，冻结期间再次失败封禁 1 天。
- 平台会话基于 Session + CSRF Token，长时间无操作后需重新登录。
:::

## 界面布局

登录后进入主界面，整体分为四个区域：

```
┌────────────────────────────────────────────────┐
│ 顶部导航栏：面包屑 · 消息报警 · 中英文切换 · 用户 │
├──────────┬─────────────────────────────────────┤
│          │                                     │
│  左侧    │           主内容区                   │
│  菜单    │        （当前页面内容）               │
│          │                                     │
├──────────┴─────────────────────────────────────┤
│ 底部交易面板（可展开/收起，仅桌面端）             │
└────────────────────────────────────────────────┘
```

- **顶部导航栏右侧**：
  - 🔔 **消息报警配置**：订阅平台事件（登录、订单、成交、通知等）的报警推送；
  - 🌐 **中英文切换**；
  - 👤 **退出系统**。
- **底部交易面板**：所有桌面端页面共享的快捷下单面板，点击中间横条展开/收起。这是手工交易与操盘手训练的核心工具，详见 [模拟盘交易](/features/sim-trading#手工下单)。

## 首页

首页提供三张折叠卡片，建议新用户先浏览：

1. **快捷键参考** —— 工作区切换与回放控制的全部快捷键（见下文）；
2. **术语解释** —— 网关、模组、策略等核心概念的官方定义；
3. **已购服务** —— 已订阅的数据服务及到期日。

## 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt + \`` | 切换到 首页 |
| `Alt + 1` | 切换到 网关管理 |
| `Alt + 2` | 切换到 模组管理 |
| `Alt + 8` | 切换到 活跃行情报价 |
| `Alt + 9` | 切换到 多图同列 |
| `Alt + 0` | 切换到 平台日志 |
| `Alt + Q` | 回放：数据预加载 / 开始回放 / 暂停回放（按当前状态智能切换） |
| `Alt + W` | 回放：逐K回放（步进一根K线） |
| `Alt + S` | 回放：状态重置 |

## 推荐使用路径

第一次使用平台，建议按以下顺序体验（尚未安装部署请先看 [安装与启动](/guide/installation)）：

1. **[模拟盘交易](/features/sim-trading)**：创建 SIM 模拟网关 → 出入金 → 手工下单，熟悉交易面板；
2. **[历史回放](/features/playback)**：创建 PLAYBACK 回放网关 → 在"多图同列"观看历史行情重演；
3. **[操盘手训练](/features/training)**：回放 + 模拟账户组合，进行手工复盘训练；
4. **[程序化交易](/features/auto-trading)**：创建回测模组验证策略 → 模拟盘试运行 → 实盘；
5. **[多账户交易](/features/multi-account)**：接入多个实盘账户，统一管理。
