类图 A：策略与模型定义层（northstar-api）

RLStrategy 定义模型的“形状”与语义钩子；observe / onAction / shouldObserve 训练与实盘共用同一代码路径。

类图 B：模型契约层（Hyperparameter 类 / Metadata 类 / VO）

Hyperparameter 类在定义 model 时声明超参数字段清单（UI 据此动态渲染）；Metadata 类按版本承载超参数取值与血缘信息，存 JSON 文件。

类图 C：训练运行时层（northstar-main / northstar-rl）

RLTrainingService 按轮驱动；TradingEnvironment 组合行情回放与账户沙箱，持有 gym 语义（reset/step/done）。

时序图 1：训练主循环（一轮 round）

轮边界调参：每轮开始重读最新超参数；串行采样多合约 → Python 无状态子进程训练 → 验证时段评估 → SSE 推送。

时序图 2：Episode 事件驱动决策循环（SMDP）

决策点由策略 shouldObserve() 事件触发；转移记录 dt（间隔 bar 数），训练按 γ^dt 折扣；区分 truncated / terminated。

时序图 3：实盘推理路径

与训练共用 observe/shouldObserve/onAction 钩子；RL 动作走普通下单链路，不绕过任何既有风控。

时序图 4：fork 再训练与血缘校验

specHash 防特征语义漂移；checkpointSignature 保证权重继承兼容；校验失败快速失败并给出结构化 diff。
